# Assinaturas de e-mail — Vix Log

## Colocar no ar (uma vez só)
1. Na organização `vixloglogistica` do GitHub, crie o repositório público **assinaturas-vixlog**.
2. Suba os 3 arquivos: `index.html`, `logo-vix.png`, `logo-vix.svg`.
3. Settings → Pages → Deploy from branch → `main` / root.
4. A logo ficará em `https://vixloglogistica.github.io/assinaturas-vixlog/logo-vix.png` (já é o padrão do gerador).
   O gerador abre em `https://vixloglogistica.github.io/assinaturas-vixlog/`.

## Gerar as assinaturas
1. Abra o gerador, cole a lista (uma pessoa por linha): `Nome ; Cargo ; e-mail ; WhatsApp`
2. Clique em **Gerar assinaturas** e, em cada pessoa, em **Copiar assinatura**.

## Instalar
- **Gmail / Google Workspace**: Configurações → Ver todas as configurações → Assinatura → Criar → Ctrl+V.
- **Outlook (novo/web)**: Configurações → Contas → Assinaturas → Ctrl+V.
- **Outlook desktop**: Arquivo → Opções → Email → Assinaturas → Nova → Ctrl+V.

Dica: Google Workspace e Microsoft 365 permitem ao administrador aplicar a assinatura de todos de uma vez (via código HTML) — dá para automatizar depois.
